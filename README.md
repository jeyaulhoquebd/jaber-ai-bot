# 🤖 জাবের (Jaber): আপনার ব্যক্তিগত AI অ্যাসিস্ট্যান্ট (Windows)

জাবের Windows-এর একটা ডেস্কটপ অ্যাপ। লিখে বা মুখে বলে তাকে কাজ দেওয়া যায়, আর সে বাংলায় কথা বলে উত্তর দেয়।

## যা যা পারে
| কাজ | কীভাবে |
|---|---|
| 💬 চ্যাট (বাংলা/ইংরেজি) | Groq / OpenRouter / Gemini / xAI Grok / Ollama-এর যেকোনো মডেল |
| 🎤 মুখে কমান্ড | 🎤 বাটন বা `Ctrl+Space` চাপুন, অথবা **"হেই জাবের, ..."** বলুন |
| 🔊 মুখে উত্তর | বাংলা কণ্ঠ (Microsoft Edge TTS, ফ্রি) |
| 🔍 ওয়েব সার্চ ও 📰 খবর | DuckDuckGo (ফ্রি, key লাগে না) |
| 📰 প্রতিদিনের খবর | নির্দিষ্ট সময়ে খবর খুঁজে বাংলা রিপোর্ট আর ফেসবুক পোস্টের ড্রাফট বানায়, তারপর `Documents\Jaber\news`-এ সেভ করে |
| 🌐 ব্রাউজার চালানো | আপনার Edge ব্রাউজার খুলে নিজে ক্লিক করে, টাইপ করে, পেজ পড়ে |
| 📘 ফেসবুকে পোস্ট/কমেন্ট | ব্রাউজার দিয়ে করে। **পোস্ট, কমেন্ট বা মেসেজ পাঠানোর আগে প্রতিবার আপনার অনুমতি চায়** |
| ✅ কাজের লিস্ট | "আজকের কাজ কী?", "বাজার করা কাজটা যোগ করো" |
| 📁 Google Drive | ফাইল খোঁজা, পড়া, সেভ করা (ঐচ্ছিক সেটআপ) |
| 🖥️ অ্যাপ খোলা | Notepad, Calculator, Explorer, Settings, Word, Excel, Chrome, Edge |

## ধাপ ১: ফ্রি API key নিন (৫ মিনিট)
1. https://console.groq.com এ যান, তারপর Google দিয়ে সাইন আপ করুন।
2. বাম পাশে **API Keys** খুলে **Create API Key** চাপুন। key-টা (`gsk_...`) কপি করে রাখুন।
   একই key দিয়ে চ্যাট আর ভয়েস (Whisper) দুটোই চলবে।

> অন্য অপশন: **OpenRouter** (openrouter.ai, `:free` লেখা মডেলগুলো ফ্রি), **Google Gemini** (aistudio.google.com),
> **Ollama** (পিসিতে অফলাইনে চলে, key লাগে না, তবে ভালো পিসি লাগে)।

## ধাপ ২: Jaber.exe বানান
এখানে দুটো উপায় আছে, যেকোনো একটা বেছে নিন।

### উপায় A: নিজের পিসিতে বানানো
1. https://www.python.org/downloads/ থেকে **Python 3.12** ইনস্টল করুন।
   ইনস্টলের সময় অবশ্যই **"Add python.exe to PATH"** টিক দেবেন।
2. এই `jaber` ফোল্ডারটা পিসিতে রাখুন।
3. **`build.bat`** ফাইলে ডাবল ক্লিক করুন। ১০–১৫ মিনিট লাগতে পারে।
4. কাজ শেষ হলে `dist\Jaber.exe` তৈরি হবে। এটাই আপনার অ্যাপ, ডেস্কটপে কপি করে নিন।

(exe না বানিয়ে আগে চালিয়ে দেখতে চাইলে `run_dev.bat` ডাবল ক্লিক করুন।)

### উপায় B: GitHub দিয়ে বানানো (পিসিতে Python লাগবে না)
1. GitHub-এ একটা রিপো বানিয়ে এই ফোল্ডারের সব ফাইল আপলোড করুন।
2. **Actions** ট্যাবে গিয়ে **Build Jaber.exe** খুলুন, তারপর **Run workflow** চাপুন।
3. ৫–১০ মিনিট পরে নিচে **Artifacts**-এ `Jaber-windows` পাবেন। ডাউনলোড করে unzip করলেই `Jaber.exe`।

## ধাপ ৩: প্রথমবার চালানো
1. `Jaber.exe` চালান। Windows "unknown publisher" দেখালে **More info**, তারপর **Run anyway** চাপুন।
2. সেটিংস খুলবে। প্রোভাইডার **Groq** রেখে API Key বসান। তারপর **মডেল লোড** চেপে লিস্ট থেকে একটা মডেল বেছে নিন
   (যেমন `openai/gpt-oss-120b`, `qwen/qwen3-32b` বা `llama-3.3-70b-versatile`)। শেষে **সেভ** চাপুন।
3. লিখে দেখুন: *"আজকের বাংলাদেশের প্রধান খবর কী?"*
4. মুখে বলতে **🎤** চাপুন। সবসময় শোনার জন্য **👂 হেই জাবের** টিক দিন, তারপর বলুন *"হেই জাবের, এখন কয়টা বাজে?"*

## ধাপ ৪: ফেসবুক সংযোগ
1. জাবেরকে বলুন: *"ফেসবুক খোলো"*। জাবের নিজের একটা Edge উইন্ডো খুলবে।
2. **সেই উইন্ডোতে নিজে একবার Facebook-এ লগইন করুন।** লগইন মনে থাকবে, কারণ প্রোফাইলটা `%APPDATA%\Jaber\browser_profile`-এ সেভ থাকে।
   জাবের কখনো আপনার পাসওয়ার্ড চায় না, দেখেও না।
3. এরপর বলতে পারবেন: *"আমার ফেসবুকে লেখো: আজ খুব সুন্দর দিন!"*
   জাবের পোস্ট বক্সে লিখবে, কিন্তু **Post বাটনে ক্লিক করার আগে আপনার কাছে Yes/No অনুমতি চাইবে।**

> ⚠️ **সতর্কতা:** Facebook স্বয়ংক্রিয় (বট) পোস্ট-কমেন্ট পছন্দ করে না। খুব বেশি বা দ্রুত অটো-পোস্ট বা কমেন্ট করলে
> অ্যাকাউন্ট সাময়িক লক হতে পারে। তাই জাবের প্রতিটা পোস্ট ও কমেন্টে আপনার অনুমতি নেয়। অন্যের পোস্টে স্প্যাম কমেন্ট করাবেন না।
> নিয়মিত পোস্টের জন্য একটা **Facebook Page** ব্যবহার করা বেশি নিরাপদ।
>
> Facebook মাঝে মাঝে তার ডিজাইন বদলায়। জাবের প্রতিবার পেজ পড়ে বাটন খোঁজে, তাই সাধারণত মানিয়ে নেয়।
> তবু কোনো ধাপে আটকে গেলে নিজে এক ক্লিক করে দিন।

## ধাপ ৫: প্রতিদিনের খবর
- ⚙ সেটিংসে **খবরের সময়** (যেমন `08:00`) আর **বিষয়** দিন। জাবের চালু থাকলে প্রতিদিন ওই সময়ে:
  খবর খুঁজবে, বাংলা রিপোর্ট বানাবে, সারাংশ মুখে শোনাবে, তারপর জিজ্ঞেস করবে *"এই পোস্টটা কি Facebook-এ দেব?"*
- যেকোনো সময় নিজে চাইলে উপরের **📰 আজকের খবর** বাটন চাপুন।
- জাবের বন্ধ থাকলেও খবর চাইলে Windows Task Scheduler-এ এটা যোগ করুন
  (Command Prompt খুলে নিচের কমান্ড দিন, পাথ নিজের মতো বদলে নিন)। এটা শুধু রিপোর্ট সেভ করে, কিছু পোস্ট করে না।
  ```bat
  schtasks /create /tn "Jaber Daily News" /tr "\"C:\Users\YOU\Desktop\Jaber.exe\" --daily-news" /sc daily /st 08:00
  ```
- Windows চালু হলেই জাবের নিজে চালু করতে চাইলে: `Win+R` চেপে `shell:startup` লিখুন, তারপর ওই ফোল্ডারে Jaber.exe-এর shortcut রাখুন।

## ধাপ ৬ (ঐচ্ছিক): Google Drive
1. https://console.cloud.google.com এ নতুন Project বানান। **APIs & Services → Library** থেকে **Google Drive API** Enable করুন।
2. **OAuth consent screen** সেট করুন (External, Test users-এ নিজের Gmail দিন)।
3. **Credentials → Create Credentials → OAuth client ID → Desktop app** বানিয়ে JSON ডাউনলোড করুন।
4. ফাইলটার নাম `credentials.json` দিয়ে `%APPDATA%\Jaber\` ফোল্ডারে রাখুন।
   (`Win+R` চেপে `%APPDATA%\Jaber` লিখলেই ফোল্ডার খুলবে।)
5. জাবেরকে বলুন *"আমার ড্রাইভে রিপোর্ট নামের ফাইল খোঁজো"*। প্রথমবার ব্রাউজারে Google অনুমতি চাইবে।

## সমস্যা হলে
| সমস্যা | সমাধান |
|---|---|
| "মডেল লোড হয়নি" | API key ঠিকমতো কপি হয়েছে কিনা দেখুন, ইন্টারনেট চেক করুন |
| `rate limit` / `429` | ফ্রি লিমিট শেষ, কিছুক্ষণ পরে চেষ্টা করুন বা ছোট মডেল বেছে নিন |
| `tool` সংক্রান্ত error | মডেলটা টুল সাপোর্ট করে না, `openai/gpt-oss-120b` বা `llama-3.3-70b-versatile` বেছে নিন |
| মাইক কাজ করে না | Windows Settings → Privacy → Microphone-এ অনুমতি দিন |
| ব্রাউজার খোলে না | Microsoft Edge আপডেট করুন |
| লগ দেখতে | `%APPDATA%\Jaber\jaber.log` |

## ফাইলগুলো কোথায় থাকে
- সেটিংস, API key, চ্যাট হিস্টরি, ব্রাউজার প্রোফাইল: `%APPDATA%\Jaber\` (key শুধু আপনার পিসিতেই থাকে)
- খবর আর নোট: `Documents\Jaber\`
